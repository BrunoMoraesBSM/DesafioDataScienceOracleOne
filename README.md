# DesafioDataScienceOracleOne

 Esse desafio se trata de uma análise dos dados de vendas de quatro lojas de um e-comerce chamado Alura Store, com objetivo de localizar a melhor opção de loja para ser fechada.

 Nessa análise encontrei diversos desafios para montar os gráficos e otimizar as linhas de código, porém superei todos entregando um bom resultado com uma análise assertiva.

 Com essa Análise, o e-comerce vai conseguir tomar uma decisão mais certeira, correndo muito menos riscos de fechar a loja errada.
